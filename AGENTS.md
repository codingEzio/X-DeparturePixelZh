# DeparturePixelZh

This repository defines the published DeparturePixelZh font family.

- `recipe.json` is the source of truth for upstream pins, identity, metrics, and glyph priority.
- Build with the pinned X-DeparturePixelZhBuilder revision; use a local builder checkout only for development.
- Run the builder `check` command before preparing a release archive.
- Keep `OFL.txt`, `NOTICE.md`, and every file under `licenses/` with redistributed fonts.
- `Build/`, `dist/`, source caches, receipts, and consumer copies are generated local state.
- Do not add unpublished applications, private paths, or machine configuration to this repository.
